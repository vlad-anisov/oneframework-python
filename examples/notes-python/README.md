# Одно приложение, три языка

Три приложения рядом — `notes-python`, `notes-js`, `notes-kotlin` — **одинаковы
снаружи**: те же модели, тот же экран, та же кнопка, тот же ответ. Различается
ровно одно: на чём написано приложение и, как следствие, чем исполняется его
логика на устройстве.

| | язык | что едет на устройство | чем исполняется |
|---|---|---|---|
| `notes-python` | Python | исходник + интерпретатор (13 МБ) | Pyodide |
| `notes-js` | JavaScript | исходник | сам webview |
| `notes-kotlin` | Kotlin | скомпилированный `.wasm` | движок WebAssembly |

## Одинаковы не на глаз

Похожесть ничего не доказывает — разойтись приложения могут в подписи поля,
в порядке колонок, в имени таблицы, и заметить это можно будет только тогда,
когда обмен сочтёт два одинаковых приложения разными.

Проверяется поэтому двумя способами, и оба прогоном.

**Объявление** — по **отпечатку**: sha256 канонического JSON каждого документа.
У всех трёх он один и тот же.

**Поведение** — по ответу: три реализации кнопки гоняются на одном и том же
входе, и ответ обязан совпасть. Отпечаток этого не ловит: тело действия в
объявление не входит, у каждого языка оно своё. Kotlin при этом проверяется
скомпилированным модулем, а не исходником, — на устройство едет он.

```bash
python3 -m pytest tests/test_three_languages.py -q
```

Различаются у них только название и цвет — этим их и отличают на устройстве.

Логика написана на стандартной библиотеке каждого языка. Сторонние библиотеки
доезжают до устройства сегодня только у питона (колёсами Pyodide); у JavaScript
и Kotlin такого механизма пока нет, и строить тройку на том, что есть у одного
из трёх, значило бы снова её развести.

## Как это устроено

Между языком и сборкой лежит **пакет объявления** — обычный JSON, в котором
записано всё, из чего состоит приложение: модели, виды, логика. Библиотека
каждого языка умеет его напечатать, сборка умеет его прочитать. Посмотреть:

```bash
python3 -m oneframework.cli.main declare examples/notes-python/app.py
```

То же самое у остальных двух — `npx oneframework declare app.mjs` и `main()`
в `App.kt`.

## Собрать

```bash
python3 -m oneframework.cli.main build web examples/notes-python/app.py
```

Разработчику на JavaScript питон писать не нужно, но поставить — нужно:
сборщик пока написан на нём. На устройство он не едет; договор выбран так,
чтобы сборщик можно было однажды переписать, не трогая библиотеки языков.
